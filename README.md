# Sutharsan M — Portfolio

A personal, responsive placement portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — mobile navigation and small interactions
- `profile.jpg` — profile photo used in the hero section
- `SutharsanResume.pdf` — resume linked from the site

## Change your photo
Replace `profile.jpg` with your preferred image, keeping the same filename. If you use a different filename, update the `src` value for `.profile-photo` in `index.html`.

## Run locally
Open `index.html` in a browser, or run it using the VS Code Live Server extension.

## Deploy
This is a static website and can be deployed to Vercel, Netlify, or GitHub Pages. For Vercel, import the GitHub repository or deploy the project folder. No build command is required.
